# SpaceVision — Заиграевский район (версия без нейросети)

## Zaigraevsky District — No ML Version

### 1. Назначение версии

Специализированная GIS-версия проекта для оценки вероятности возникновения
лесных пожаров на территории **Заиграевского района Республики Бурятия
(Россия)**. Дороги загружаются из ESRI Shapefile, а не распознаются нейросетью.

### 2. Отличие от основной версии

Основная (AI) версия живёт в ветке `Train-brach`:

```
космоснимок → нейросеть → сегментация дорог → маска дорог → карта → риск
```

Эта ветка (`feature/zaigraevsky-no-ml`) использует другой pipeline:

```
SHP с дорогами → загрузка геометрий → проверка/преобразование CRS
→ отображение на карте → расстояние до ближайшей дороги (метры)
→ коэффициент влияния дороги I(R) → вероятность пожара → карта риска
```

### 3. Отсутствие нейросети

В этой версии **нет** нейросетевого pipeline:

- нет model weights (`best_model.pth`);
- нет загрузки модели и inference;
- нет torch / torchvision / segmentation-models-pytorch;
- не требуется GPU / CUDA;
- нет сегментации дорог и растровых масок;
- нет inference API и AI-эндпоинтов.

### 4. Источник дорог — SHP

Дороги загружаются из **ESRI Shapefile** через GeoPandas и передаются на
frontend как GeoJSON (WGS84). Путь по умолчанию: `gis/roads/roads.shp`
(настраивается через `ROADS_SHP_PATH`). Файл `.prj` обязателен.

### 5. Необходимые файлы SHP

```
.shp  .shx  .dbf  .prj  (.cpg)
```

### 6. Структура SHP

Shapefile должен содержать линейные (или мультилинейные) геометрии дорог.
Атрибутивная таблица не используется для расчёта — важно наличие корректной
геометрии и CRS.

### 7. CRS

- CRS SHP считывается из `.prj`. Если `.prj` отсутствует или пуст — выводится
  понятная ошибка, CRS **не угадывается**.
- Для расчёта расстояния геометрии перепроецируются в **метрическую** проекцию
  (UTM-зону, вычисляемую по центроиду данных, либо заданную через `METRIC_CRS`).

### 8. Запуск проекта

```bash
# backend (порт 8000)
python -m pip install -r backend/requirements.txt
python -m uvicorn app.main:app --reload --host 0.0.0.0 --port 8000 --app-dir backend

# frontend (порт 5173)
cd frontend
npm install
npm run dev
```

Или одной командой из корня: `npm start`.

Демо-доступ: `admin / admin123`, `operator / operator123`.

### 9. Расчёт расстояния

Для точки вычисляется `R` — расстояние до **ближайшей** дороги, **в метрах**,
в метрической CRS (не в градусах). Точка на дороге даёт `R = 0`.

### 10. Функция влияния дороги

```
I(R) = 1 / (1 + R / R0)
```

Свойства: `I(0) = 1`, `I(R0) = 0.5`, `I(2·R0) ≈ 0.333`, `I(4·R0) = 0.2`,
`I(R) → 0` при `R → ∞`. Это сглаженная нормированная форма `1/R` без
сингулярности в нуле.

### 11. Формула вероятности пожара

```
P_fire = 1 - (1 - P_base) · (1 - alpha · I(R))
```

где `P_base ∈ [0,1]` — базовая вероятность (существующая rule-based модель
проекта, сохранённая без изменений и нормированная к `[0,1]`), `I(R) ∈ [0,1]`,
`alpha ∈ [0,1]`. Гарантируется `0 ≤ P_fire ≤ 1` и `P_fire ≥ P_base` при
`alpha ≥ 0`.

### 12. Параметры R0 и alpha

| Параметр | Значение по умолчанию | Переменная окружения |
|----------|----------------------|----------------------|
| `R0`     | 500 м                | `R0_METERS`          |
| `alpha`  | 0.5                  | `ALPHA`              |

### 13. Необходимые геоданные

- Shapefile дорог Заиграевского района (обязательно);
- при наличии — границы лесничеств, лесных массивов, опушек (необязательно;
  архитектура допускает добавление этих факторов позже).

В репозитории нет готовых границ района/лесничеств и статистики пожаров — они
не выдумываются, а подключаются пользователем.

### 14. Ограничения новой версии

- Работает только для территории Заиграевского района.
- Не содержит нейросети, model weights и inference.
- Требует предоставления реального SHP с корректным `.prj`.
- Базовая вероятность `P_base` сохраняет legacy-факторы (в т.ч. OSM-контекст
  дорог/населённых пунктов), а новый фактор `I(R)` добавляется поверх неё.

## Структура backend

```
backend/app/
  config.py          # пути и параметры (SHP, R0, alpha, CRS)
  road_data.py       # загрузка SHP (RoadDataProvider)
  gis.py             # проверка/выбор/преобразование CRS
  distance.py        # расстояние до ближайшей дороги (метры)
  road_influence.py  # I(R) = 1 / (1 + R / R0)
  fire_risk.py       # P_base и P_fire
  osm.py             # legacy-контекст OSM для P_base
  main.py            # FastAPI: /auth/login, /health, /roads/geojson, /roads/status, /roads/upload, /risk/point
```

## Тесты

```bash
cd backend
python -m pytest
```

Покрывают: загрузку SHP, отсутствующий SHP, отсутствующий `.prj`, пустой SHP,
несколько дорог, CRS/преобразование, расстояние (точка на дороге/далеко),
`I(0)=1`, `I(R0)=0.5`, монотонность, границы `0 ≤ P_fire ≤ 1`,
`P_fire ≥ P_base`, а также интеграционный тест
SHP → ближайшая дорога → R → I(R) → P_fire.
