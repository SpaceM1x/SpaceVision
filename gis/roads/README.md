# Подключение дорог (ESRI Shapefile)

В эту папку необходимо положить shapefile с дорогами **Заиграевского района
Республики Бурятия**. Нейросеть в этой версии не используется — дороги
загружаются непосредственно из SHP.

## Требуемые файлы

Положите в `gis/roads/` набор файлов shapefile с общим именем `roads`:

```
gis/roads/roads.shp   — геометрии дорог
gis/roads/roads.shx   — индекс геометрий
gis/roads/roads.dbf   — атрибутивная таблица
gis/roads/roads.prj   — описание системы координат (CRS)
gis/roads/roads.cpg   — (необязательно) кодировка атрибутов
```

Если файлы называются иначе, задайте путь через переменную окружения:

```bash
ROADS_SHP_PATH=/path/to/your/roads.shp
```

## Обязательные требования к CRS

- Файл `.prj` **обязателен** и должен содержать корректное описание CRS.
- Если `.prj` отсутствует или пуст, приложение **не будет угадывать CRS** —
  оно вернёт понятную ошибку.
- Допустим любой корректный CRS (например, `EPSG:4326` или местная проекция).
  Для расчёта расстояния до дороги геометрии автоматически перепроецируются
  в метрическую проекцию (UTM-зону, вычисляемую по центроиду данных, либо
  заданную через `METRIC_CRS`).

## Параметры модели (переменные окружения)

| Переменная        | Назначение                        | По умолчанию |
|-------------------|-----------------------------------|--------------|
| `ROADS_SHP_PATH`  | путь к shapefile дорог            | `gis/roads/roads.shp` |
| `R0_METERS`       | характерное расстояние влияния R0 | `500`        |
| `ALPHA`           | максимальное влияние дороги       | `0.5`        |
| `METRIC_CRS`      | метрическая CRS (напр. `EPSG:32649`) | авто (UTM по центроиду) |

> Файлы данных (`*.shp`, `*.shx`, `*.dbf`, `*.prj`, `*.cpg`) исключены из Git
> через `.gitignore` — предоставьте собственные реальные данные.
